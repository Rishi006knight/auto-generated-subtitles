Subtitle AI — Verification Testbed

Simulate real-time video playback and speech synthesis to test Whisper ASR & Chrome Extension overlay

Speech State: Idle

How to test with the Chrome Extension:

  1. Start Backend: Run python main.py in the backend/ folder.
  2. Load Extension: Open chrome://extensions in Chrome, enable Developer mode, and click Load unpacked → select the extension/ folder.
  3. Open Testbed: Keep this page open and click the Subtitle AI extension icon in the toolbar.
  4. Start Generation: Click Generate Subtitles in the popup and press Speak Dialogue or play audio.
  5. Watch Real-Time Subtitles: The subtitle box will automatically overlay above the video player in real-time!
